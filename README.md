# moldrepo

Mold numeric repo values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/moldrepo/

## Install / run

```bash
git clone https://github.com/theworker02/moldrepo.git
cd moldrepo
node src/cli.js
node --test
```
